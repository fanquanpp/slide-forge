## 映射依据说明

- **编程教学课件**：画像中大量 `.py/.java/.html/.md` 学习资料与网课录屏，属于「把知识讲给别人听」的场景，
  故配置偏清晰层级与代码感的风格（极简 / 终端 / 柔和科技）。
- **游戏设计提案**：Godot 工程与游戏资源占比高，需要「可展示玩法与美术」的风格，故用暗黑霓虹与复古像素。
- **像素与美术作品集**：像素/MMD/Blender 素材量大，作品集需要图像优先的大图版式，故配置图集网格友好的风格。
- **社团活动策划**：章程、活动策划、申报模板直接对应策划案 / 申报 / 竞聘类版面。
- 其余分类同理，均以「画像中真实存在的文件类型 → 真实使用场景 → 版面原型」推导，而非泛泛罗列常见 PPT 类型。
