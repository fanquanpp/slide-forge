使用指南

1 · 直接编辑

下载 .pptx 用 PowerPoint / WPS / Keynote / LibreOffice 打开，文本框、形状、配色、图片位均可直接改，不破坏版式。.potx 可放入模板目录后直接「新建」。

2 · 换配色与字体

页面颜色都写在各形状上，批量替换主题色即可全局换肤；标题 / 正文字体在 generator/themes.py 的 title_font / body_font 定义。

3 · 重新生成

  1. pip install -r generator/requirements.txt
  2. python generator/build.py templates
  3. python scripts/build_site.py
python generator/build.py templates     # 生成全部模版与 index.manifest.json
python generator/validate.py templates  # 校验可打开性 / 版面数 / 内容类型
python scripts/build_site.py            # 重建本站点与风格预览图
